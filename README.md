## 🚀 How to Deploy on GitHub Pages (Step-by-Step)

You can publish this portfolio to the web for free using **GitHub Pages** in under 3 minutes:

### Step 1: Create a New GitHub Repository
1. Log in to [GitHub](https://github.com).
2. Click the **+** (plus) icon in the top right and select **New repository**.
3. Name your repository (e.g., `manu-portfolio` or `manu.github.io`).
4. Set the repository to **Public**.
5. Do NOT check "Initialize this repository with a README" (we already have all the files ready).
6. Click **Create repository**.

### Step 2: Upload Files
1. Extract the `manu-kawaii-portfolio.zip` file onto your computer.
2. In your newly created GitHub repository page, click **uploading an existing file**.
3. Drag and drop all the extracted files:
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
4. Click **Commit changes**.

*(Alternatively, if you use Git in the terminal:)*
```bash
git init
git add .
git commit -m "Initial kawaii portfolio commit 🌸"
git branch -M main
git remote add origin https://github.com/<your-username>/<repo-name>.git
git push -u origin main
```

### Step 3: Enable GitHub Pages
1. Go to your repository's **Settings** tab.
2. In the left sidebar, click on **Pages** (under the "Code and automation" section).
3. Under **Build and deployment** > **Branch**:
   - Select `main` (or `master`) branch.
   - Leave the folder as `/ (root)`.
4. Click **Save**.

### Step 4: Visit Your Live Site! 🎉
- Wait 30–60 seconds for GitHub to build the site.
- Refresh the **Pages** settings tab. You will see a banner at the top:
  > *"Your site is live at https://<your-username>.github.io/<repo-name>/"*
- Click the link and enjoy Ms. Manu's kawaii portfolio!
